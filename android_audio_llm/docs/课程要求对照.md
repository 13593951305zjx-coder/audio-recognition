# 移动终端项目实训课程要求对照

本项目把已有音频识别系统接入 Android 手机端。客户端按任务书的 Android JAVA 要求组织为原生 Java Activity，使用本机 SQLite 保存记录和完整识别结果，并通过 HTTP 调用原有电脑端 Python 服务。下表列出课程原文、实现位置和验收方法；验收动作需要在实际构建和设备运行后记录结果，不表示已经全部通过。

## 扩展功能及环境表述

R1 第 1 页和 R2 第 2 页规定 1—2 人一组；两人组必须明确模块分工并实现扩展功能。R1 第 3 页还要求两人共同参加开题、中期和答辩，并交叉测试。分组人数和实际分工由学生填写，软件文档不代填姓名、学号、班级或指导教师。

R1 第 1 页把服务器存储、接口、数据库和软件更新列为可选扩展。R2 第 5 页进一步说明：若选择数据服务器端存储，需要编写服务器端接口程序并建立服务器端数据库。单人项目可以按选做项处理；两人项目仍须按课程规则完成扩展，不能因该页写“可选”而免除。

本项目采用已有电脑端 Python 服务执行语音识别、Ollama 文本整理和音高运算，手机端通过 HTTP 上传并查询任务及历史。手机可通过同一局域网连接电脑，也可在 USB 调试连接后使用 `adb reverse tcp:8000 tcp:8000`，将手机的 `127.0.0.1:8000` 转发到电脑服务。服务端接口、服务端持久化及恢复行为需要联调验收；手机 SQLite 仅证明本机存储，不能替代服务端数据库的验收。

R1 第 2 页原文列出的开发环境是“Android Studio、Android SDK、Tomcat、Mysql等”。Android Studio 和 SDK 用于本项目 Android 工程；当前服务架构采用 Python。材料未明确写“必须同时使用全部列举工具”，但也没有直接把 Tomcat/MySQL 写为独立选做项。本项目不声称已实现 Tomcat/MySQL；若验收要求特定服务器技术，应按教师确认的技术要求调整。

断开电脑服务时，验收重点是本机录音、文件保存、本机媒体播放和已有 SQLite 记录访问。新的转写、摘要和音高计算仍依赖服务端及相应模型，不能描述成手机离线完成 AI 识别。
