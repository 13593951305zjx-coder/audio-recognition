# 音频智记 Android 课程版

这是原生 Java 安卓应用，按任务书组织为9个 Activity，使用 SQLite、手机私有文件、MediaRecorder、MediaPlayer/VideoView 和 Canvas。现有电脑版网页继续保留。

## USB 真机安装

1. 手机需要 Android 8.0 或以上。用支持数据传输的USB线连接电脑，开启开发者选项中的USB调试，并在手机上允许电脑授权。
2. 在整个项目的根文件夹双击 connect_android.cmd。脚本检查设备，启动或复用本机音频服务，建立USB转发，安装APK并打开应用。多个设备时需传入 -Serial 设备编号。
3. 手机应用“设置”使用 http://127.0.0.1:8000 并检测连接。电脑服务使用其他8001—8010端口时，脚本也会映射到手机8000，无需局域网。
4. 首次录音允许麦克风权限。录音结束后先保存到手机，再提交整理；也可在导入页批量选择文件。拔插USB或重启后，重新运行连接脚本。

APK在 release/AudioInsight-debug.apk。也可先单独安装，再运行连接脚本。仅恢复连接而不安装可运行 connect_android.cmd -ConnectionOnly。

## 可用功能及运行边界

- 启动动画、首页、录音、导入队列、识别结果、历史、声音分析、设置、关于，共9个实际Activity。
- 最长5分钟录音、实时音量条、离开录音页自动结束保存；导入每个文件不超过50MB和5分钟。
- 持久化手机队列依次上传。电脑已接受的任务在退出手机页面后继续；重连可刷新任务状态或同步电脑历史。
- 分句时间段、说话人、关键词搜索、待核对语句、原声/视频定位与片段播放、文字修订、选句AI总结、摘要、关键词及待办。
- TXT导出与复制，本机历史查询、收藏、重命名及删除，音高曲线和按分句时长估算的发言占比。

手机可离线启动，录音、导入、本机媒体播放和已缓存结果可在未连接电脑时使用。新的转写、AI总结及音高计算由电脑本地Whisper/Ollama等程序完成，需要电脑服务和USB；模型没有打包进手机，不需要API密钥。电脑版的波形拆合句、实时转写和电脑系统声音混录继续在原网页版使用。

上传中断并提示“上传待确认”时，先同步电脑历史，确认是否已经接收，避免重复提交。本机删除只移除手机记录和文件，不删除电脑原始记录。

## 工程与构建

源码：app/src/main/java/com/example/audioinsight/。ui负责原生页面与绘图；data负责SQLite、HTTP、导入和队列。完整服务响应以JSON保留；修订带原文与分句结构版本校验。

构建：AGP8.6.1、Gradle8.7、JDK17—21、SDK35、Build Tools36.0.0，minSdk26/targetSdk35。附官方Gradle Wrapper及分发校验值。

在项目根目录双击 build_android.cmd，或在此目录用PowerShell运行 build.ps1。脚本自动检测本机JDK/SDK，可用 -JdkPath 和 -SdkPath 指定路径，首次构建需要下载依赖；仅修改当前进程环境，使用现有系统代理或 -Proxy 参数。

原始APK输出：app/build/outputs/apk/debug/app-debug.apk。构建和校验材料在项目根 verification/。可以用Android Studio打开本目录；本次验证使用命令行构建。
